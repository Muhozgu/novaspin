# Novaspin Casino - Global iGaming Performance Analytics

An end-to-end BI project analyzing 10 years (2016–2026) of performance data for **NovaSpin**, a fictional global online casino operator. The project simulates NovaSpin's expansion from 4 founding European markets to 54 countries worldwide, and models player acquisition, retention, and revenue trends across that growth — from a Python data generator through a Snowflake + dbt pipeline into a Power BI semantic model.

> **Note:** NovaSpin is a fictional company. All data is synthetically generated for portfolio/practice purposes and contains no real player, financial, or operator information.

---

## Project Goals

- Practice building a full BI pipeline (generation → warehouse → transformation → semantic model → dashboard) end to end
- Model realistic iGaming KPIs: GGR, NGR, player retention/churn, ARPU, market expansion
- Apply a medallion (Bronze/Silver/Gold) architecture with dbt
- Produce a Power BI report suitable for a portfolio walkthrough

## Dataset

Generated by [`novaspin_casino_data_generator.py`](./novaspin_casino_data_generator.py). Three linked tables:

### `dim_markets.csv`
One row per country NovaSpin operates in — launch date, region, currency, regulatory status, and market tier. Encodes the expansion story: 4 markets in 2016 → 54 by 2026.

### `dim_players.csv`
One row per player — registration date/country (constrained to markets already live at that time), acquisition channel, VIP tier, device, and churn status.

### `fact_game_sessions.csv`
One row per game session — bets, wins, GGR, NGR, bonus cost, session duration, deposits/withdrawals — referencing `player_id` and `country_code`.

## Setup

1. **Generate the data**
   ```bash
   pip install pandas numpy faker
   python generator/novaspin_casino_data_generator.py --players 8000 --sessions 150000 --output-dir data/raw
   ```

2. **Load into Snowflake (Bronze)**
   Load the three CSVs as-is into a `RAW`/`BRONZE` schema via Snowsight's upload wizard or the `snowflake-connector-python` package.

3. **Run dbt (Silver → Gold)**
   ```bash
   cd dbt
   dbt deps
   dbt run
   dbt test
   ```
   Silver models cast types and standardize columns; Gold models build the analytics-ready star schema (`fact_game_sessions`, `dim_players`, `dim_markets`, `dim_date`).

4. **Connect Power BI**
   Open Power BI Desktop → Get Data → Snowflake → point at the `GOLD` schema → Import mode. Confirm one-to-many relationships from each dim table to `fact_game_sessions` in Model view.

## Key Metrics Modeled

- **GGR** (Gross Gaming Revenue) and **NGR** (Net Gaming Revenue)
- Player acquisition by channel, market, and VIP tier
- Retention / churn rate over tenure
- ARPU and sessions per player
- Revenue by game, game type, provider, and platform
- Market expansion timeline and revenue contribution by region
